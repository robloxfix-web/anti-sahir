# 🌙 مكافح السهر — Anti-Sahir

تطبيق Android ذكي يساعدك على التخلص من عادة السهر تدريجياً حتى تصل إلى نوم صحي الساعة **10:30 مساءً**.

---

## 💡 كيف يعمل؟

1. **تُدخل وقت نومك الحالي** (مثلاً: 2:00 صباحاً)
2. **كل يوم** عند حلول وقت نومك المحدد → يُغلق الهاتف تلقائياً
3. **في اليوم التالي** يتقدم وقت الإغلاق **15 دقيقة** تلقائياً
4. يستمر التقليص التدريجي حتى **10:30 مساءً** ثم يثبت عنده

### مثال:
| اليوم | وقت الإغلاق |
|-------|------------|
| 1     | 2:00 ص    |
| 2     | 1:45 ص    |
| 3     | 1:30 ص    |
| ...   | ...        |
| N     | **10:30 م** ✅ |

---

## 🔧 المتطلبات

- Android 7.0 (API 24) أو أعلى
- Android Studio Hedgehog أو أحدث
- JDK 8

---

## 🚀 طريقة البناء

```bash
# 1. استنسخ المستودع
git clone https://github.com/YOUR_USERNAME/anti-sahir.git
cd anti-sahir

# 2. افتح المشروع في Android Studio
# File → Open → اختر مجلد المشروع

# 3. أو بناء من سطر الأوامر
./gradlew assembleDebug

# 4. ملف APK سيكون في:
# app/build/outputs/apk/debug/app-debug.apk
```

---

## 📱 طريقة الاستخدام

1. **ثبّت التطبيق** على هاتفك
2. عند فتحه لأول مرة، **اقبل طلب صلاحية المشرف** (ضروري لإغلاق الشاشة)
3. **اختر وقت نومك الحالي** من ضبط الوقت
4. اضغط **"ابدأ الرحلة"**
5. التطبيق سيعمل تلقائياً كل يوم في الخلفية ✅

> ⚠️ **ملاحظة:** صلاحية "مشرف الجهاز" مطلوبة لتشغيل ميزة إغلاق الشاشة. هذه الصلاحية آمنة تماماً ولا تمنح التطبيق أي وصول لبياناتك.

## 🧠 الخوارزمية الذكية

```kotlin
// كل يوم عند تشغيل المنبه:
val newTime = currentSleepTime - 15.minutes
if (newTime > TARGET_10_30_PM) {
    scheduleAlarm(newTime)      // جدول الغد أبكر بـ 15 دقيقة
} else {
    scheduleAlarm(TARGET_10_30_PM)  // وصلنا الهدف! ثبّت عند 10:30
}
lockScreen()                    // أغلق الشاشة الآن
```
